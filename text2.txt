+ Components
 Thành phần giúp chia các UI giao diện người dùng thành các phần nhỏ để dễ dàng quản lý và tái sử dụng 
 ex: header, footer, sidebar
 các bước tạo : b1: trong folder src tạo 1 folder tên Components
                b2: trong components tạo 1 folder mới đặt tên theo đúng ý nghĩa của khối đó 
                b3: tạo 1 file mới đặt tên là index.js sau đó viết 1 function tên là header và export default 
                b4: import

+ props là 1 object được truyền vào component - cho phép giao tiếp giữa các component với nhau bằng cách truyền tham số 
qua lại giâuwx các component - khi 1 components cha được truyền cho con 1 props thì con chỉ có thể đọc và ko có quyền chỉnh 
sửa - truyền giống như thêm 1 attributes cho 1 element html - String - Number - Boolean - Undefined - Nulll - Symbol -
Function - Object - Array
